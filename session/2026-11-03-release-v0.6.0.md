# 2026-11-03 - release v0.6.0

Contents: `lazyai launch` reads the same line as `n`
(`KIND [DIR] [NAME] [-- AGENT-ARGS...]`), examples in every command's
help and `lazyai examples [COMMAND]` (details in
session/2026-11-03-release-v0.5.0.md, "After v0.5.0").
