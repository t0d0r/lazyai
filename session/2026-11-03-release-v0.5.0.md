## Fix before release

- make test-linux failed in TestLaunchSendPanes: the launched pane was
  not found. tmux 3.4 prints an empty session_last_attached for a
  session never attached, so the list-panes line ends in a tab;
  parsePanes trimmed all whitespace from the output and the last line
  lost its sixth field. Only line ends are trimmed now; TestParsePanes
  has such a line last. macOS tmux was not affected in the tests.
