## After v0.5.0: one launch line, examples in help

- `lazyai launch` reads the same line as `n`:
  `KIND [DIR] [NAME] [-- AGENT-ARGS...]`, through one parser
  (agent.ParseLaunch, agent.ExpandDir) used by the CLI and the TUI.
  `--dir` is the base for DIR; `--name` and a positional NAME together
  are a usage error; a `-word` before `--` is a usage error that says
  agent arguments go after `--`. Unknown kinds stay exit status 1.
- Breaking for the CLI: agent arguments need `--`
  (`lazyai launch ollama -- run llama3.2`). Mention in the next release
  notes.
- Help: every command's help ends with Examples; `lazyai examples
  [COMMAND]` prints them (examples.go); the top-level usage shows the
  launch line, the kinds wrapped at 80 columns, and points to
  `examples`.
- Checked by hand: `lazyai launch cat sub lztest` from a scratch
  directory starts tmux session lazyai-lztest in `sub`; `-x` before `--`
  and a fourth word exit 2 with the usage message.
- Tests: TestExamples, TestLaunchLine, TestParseLaunch (dash words).
