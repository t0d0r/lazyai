# Specs

- `overview.md` - goal, scope, non-goals, decisions
- `discovery.md` - finding agents, classification, status, metadata
- `control.md` - stop, launch, attach, send, rename, and their safety rules
- `tui.md` - dashboard layouts (split, detail, lists, screen on `v`), keys, watch
  flags (shared with the CLI)
- `cli.md` - subcommands, one per TUI action, AGENT references, watch events
- `release.md` - release tarballs, `make dist`, release steps, secret scanning
- `update.md` - `lazyai update`: find, check and install the latest release
